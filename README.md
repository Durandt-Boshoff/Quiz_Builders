# Quiz Builders

## Project Description

Quiz Builders is an interactive web-based quiz application that allows users to test their knowledge across different topics.

Users can select a topic, read the quiz instructions, answer multiple-choice questions, keep track of their progress, and receive a final score with detailed feedback.

The application was designed with a clean, modern interface and includes features such as a countdown timer, question navigation, difficulty levels, answer reviews, and a leaderboard system.

---

## Features

### Topic Selection
Users can choose between four different quiz topics:

- History
- Artificial Intelligence
- Psychology
- Entertainment

Each topic contains 15 questions divided into three difficulty levels:

- 5 Easy questions
- 5 Medium questions
- 5 Hard questions

### Quiz Instructions
Before starting a quiz, users are shown:

- The selected quiz topic
- Number of questions
- Total time available
- Quiz rules and instructions

### Multiple-Choice Questions
Each question contains four possible answers.

Users can select one answer and change their selection before submitting the quiz.
